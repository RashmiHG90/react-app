For testing react in vitest --
npm install -D vitest jsdom @testing-library/react @testing-library/jest-dom

For testing you have to make below changes
1. add these configuration to eslint.config.js
globals: {
        ...globals.browser,
        ...globals.vitest,
      },
2.add below lines to vite.config.js
test:{
    environment: 'jsdom',
    globals:true,
    setupFiles: "./src/setupTests.js"
  },
3.Have setupTests - for mock test data
4.Individual Component test files
